<Question>经典 Transformer 的每个模块分别干什么？</Question>
<Formula tex={String.raw`\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V`} />
<Io />
<Steps>
<Step title={"输入先变成数字"} example={"「我 爱 你」→ [4,5,6] → 三行向量"}>
Tokenizer 先把文字切成 Token，再映射到 Token ID；Embedding 表按 ID 找到向量；位置编码补充顺序信息。
</Step>
<Step title={"Encoder 读懂源句"} example={"得到 H_enc，每行代表一个源位置的上下文信息"}>
Self-Attention 允许每个源 Token 关注所有有效源位置。FFN 再逐位置加工表示，残差与归一化帮助稳定信息传递。
</Step>
<Step title={"Decoder 逐步准备输出"} example={"<bos> → 预测 I → 输入 <bos> I → 预测 love"}>
Masked Self-Attention 只看当前及之前的目标位置；Cross-Attention 再用目标侧 Q 查询源句的 K、V。
</Step>
<Step title={"投影、训练或生成"} example={"Logits → Softmax → Token 预测"}>
输出层把隐藏向量变成词表 Logits。训练时计算 Loss 并反向传播；推理时选择一个 Token 追加到前缀。
</Step>
</Steps>
